ModeGTA V multiplayer (mod)
This is a MyMP server — the game runs inside GTA V, like FiveM.
There is no web version of the game. To play:
  1. Run MyMP.exe (it installs the client into your GTA V folder and launches the game), or copy MyMP.asi + dinput8.dll into your GTA V folder and launch GTA V.
  2. The client connects automatically. In-game: T chat, N talk, P player list.
